# v2.2 串口使用说明

详细协议见 [serial_commands.md](serial_commands.md)。本页提供实机测试时最常用的操作顺序。

## 连接配置

```text
115200 / 8N1 / 文本模式 / CRLF
```

测试前先发送：

```text
stop
status
```

确认 `enable:0,State:IDLE,PWM:0,fault:NONE` 后再进行其他操作。

## 常用运行序列

```text
set target uart
kp=0.05
ki=0
kd=0
t=600
run=1
status
stop
status
```

`run=1` 成功返回 `OK:RUN`；`stop` 成功返回 `OK:STOPPED`。运行后 status 应为 `enable:1,State:RUN`，停止后应为 `enable:0,State:IDLE,PWM:0`。

## 参数持久化序列

```text
stop
kp=0.06
ki=0.01
kd=0.02
save params
```

`save params`、`load params`、`reset params` 仅在 IDLE 状态可用。它们只保存 `kp/ki/kd`；要验证重启加载，必须断开并恢复 MCU 供电或使用硬件 Reset，不能使用 `rst`。

## 错误命令观察

```text
t=1001
t=abc
STATUS
```

当前预期分别是 `ERR:OUT_OF_RANGE`、`ERR:BAD_INT` 和 `ERR:BAD_CMD`。错误输入不应改变停止状态、target 或 PID 参数。
