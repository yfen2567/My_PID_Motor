# My_PID_Motor v2.2 非法/越界命令回归计划

> 当前文档只是测试计划，不代表回归已经执行或通过。

## 1. 测试目标

验证代表性的非法、越界和不符合当前协议的输入会被明确拒绝，不会意外改变 enable、State、source、target、PID、PWM 或 fault，也不会导致串口失联或系统复位。

## 2. 前置条件

- 使用真实 CRLF；
- 测试前发送 `stop`，确认 `enable:0,State:IDLE,PWM:0`；
- 目标源设为 UART；
- 保存测试前完整 status 作为状态基线；
- 当前代码范围已复核：target 为 `-1000～1000`，绝对值小于 500 也是范围错误；PID 参数为 `0～100`。本轮协议固定为：数值越界返回 `ERR:OUT_OF_RANGE`，`t=` 后整数格式错误返回 `ERR:BAD_INT`，未知命令返回 `ERR:BAD_CMD`；
- 测试期间不发送 `run=1`，不进行命令压力或行结束符测试。

## 3. 串口命令序列

```text
stop
set target uart
kp=0.05
ki=0
kd=0
t=600
status

t=1001
t=-1001
t=499
t=-499
t=abc
kp=-0.01
kp=100.01
STATUS

status
```

以上包含 8 个代表性异常输入，不扩展为大而全的人工解析器单元测试。

## 4. 期望输出

| 输入 | 当前代码预期 |
| --- | --- |
| `t=1001` | `ERR:OUT_OF_RANGE` |
| `t=-1001` | `ERR:OUT_OF_RANGE` |
| `t=499` | `ERR:OUT_OF_RANGE` |
| `t=-499` | `ERR:OUT_OF_RANGE` |
| `t=abc` | `ERR:BAD_INT` |
| `kp=-0.01` | `ERR:OUT_OF_RANGE` |
| `kp=100.01` | `ERR:OUT_OF_RANGE` |
| `STATUS` | `ERR:BAD_CMD`，当前命令区分大小写 |

最终 status 应与异常输入前基线保持一致：`enable:0`、`State:IDLE`、`source:Uart`、`target:600`、`PWM:0`、`fault:NONE`、`kp:0.050`、`ki:0.000`、`kd:0.000`。`actual`、`delta`、ADC 与 `ms` 是采样字段，不要求逐值相同。

以上是基于当前代码的预期，不是实测结果。

## 6. PASS / FAIL 判定规则

### PASS

- 8 个异常输入均返回表中对应错误；
- 8 个异常输入均不返回任何 `OK:` 成功文本；
- 最终 status 的控制状态与基线一致；
- 串口仍可响应 status，没有失联、复位或不可解释 fault；
- 原始 TX/RX 日志完整。

### FAIL

- 非法/越界输入被接受、入队或改变控制状态；
- 错误类型与当前冻结协议不一致且没有变更说明；
- target、PID、source、enable、State、PWM 或 fault 被异常输入意外改变；
- status 无响应、日志中断或出现疑似复位；
- 缺少原始日志导致无法逐条对应输入和返回。

## 7. 不能外推的边界

本计划只覆盖 8 个高价值代表输入，不能证明所有字符串、超长行、编码、并发、队列压力、模糊测试或恶意输入都安全。它也不验证 UART 电气质量、行结束符兼容性、动态内存极限或 100 条命令压力。
