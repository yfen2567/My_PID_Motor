# v2.4 停转重启辅助测试矩阵

## 测试前提

- 使用同一份 v2.4 固件和同一组 PID 参数；
- 电机固定、空载、供电稳定；
- 保留完整串口原始日志；
- 异常声音、剧烈振动、发热、失控时立即 `stop`，必要时断电；
- 第一轮不改 PID、前馈和编码器测速参数。

## 矩阵

| 编号 | 场景 | 操作 | 重点观察 | 期望 |
|---|---|---|---|---|
| R0 | 直接启动 500 | `stop; t=500; run=1` | startup boost、recovery state | 只出现启动 boost，不出现 recovery |
| R1 | 正常 800→500 | `t=800; run=1; 等稳定; t=500` | actual、delta、PWM、recovery attempt | 电机持续运行；若未停转，不触发 recovery |
| R2 | 复现疑似停转 | 重复 R1，多轮运行 | 停转前后 actual/delta/PWM、恢复快照 | 若 actual/delta 持续为零，触发一次有限恢复 |
| R3 | 恢复成功 | 在 R2 中观察 boost 后速度恢复 | boost 时长、恢复时间、attempt | 恢复到 RUN，不连续重复大 PWM |
| R4 | 500→800 | `t=500` 稳定后 `t=800` | 是否误触发 recovery | 正常升速，不触发 recovery |
| R5 | 反向切换 | `t=800` 后 `t=-500` | sign-change boost 与 recovery 区分 | 只使用反向切换既有逻辑 |
| R6 | 重复相同目标 | 运行中重复 `t=500` | 是否产生无意义 boost | 不应仅因重复命令触发 recovery |
| R7 | stop 清理 | 任一运行阶段发送 `stop` | state、计数器、attempt | IDLE、PWM=0，恢复状态清零 |
| R8 | 恢复失败保护 | 在安全条件下模拟持续无脉冲/堵转 | 最大尝试次数、lockout/fault | 不无限重复 boost，保留 fault/snapshot 证据 |

## 每轮必须记录

```text
target
actual
encoder_delta
PWM
State
fault
recovery_state
recovery_attempt
recovery_event
```

## 判定原则

- R0、R1、R4、R5、R6、R7 是回归项，重点是不能引入误触发；
- R2、R3 验证“停转后能否有限次自救”；
- R8 验证保护边界，重点不是一定恢复，而是不能无限制施加 boost；
- 若 R2 无法稳定复现，记录为“未复现”，不能把一次正常运行写成修复成功；
- 若恢复成功但没有恢复前后快照，测试链路仍不完整。
