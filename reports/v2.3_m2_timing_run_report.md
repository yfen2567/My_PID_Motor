# v2.3.1 M2 电机运行时序报告

## 1. 测试结论

**PASS**

本次在 UART 目标源、`target=600`、电机运行条件下采集 20 个时序样本，确认闭环运行使控制计算时间增加，但没有破坏 10 ms 控制周期，也没有产生 fault、通信错误或异常停止状态。

## 3. 测试过程

```text
stop
set target uart
t=600
run=1
等待运行稳定
采集 20 次 timing stats
comm stats
stop
status
```

运行阶段的 status 始终保持 `enable=1, State=RUN, source=Uart, target=600, fault=NONE`。实际速度在 `557～600` 附近，PWM 约为 `128～130`，符合当前空载闭环运行现象。

## 4. 时序结果

20 个 `TIMING_STATS` 样本的观测范围：

- `period_us`：`9999～10002`；
- `exec_us`：`60～65`；
- `tick_exec_us`：`54～59`；
- `timeout_count`：全程保持 `0`。

与 M1 IDLE 基线相比：

| 状态 | `exec_us` | `tick_exec_us` | `timeout_count` |
| --- | ---: | ---: | ---: |
| IDLE 基线 | 20 | 14 | 0 |
| 电机运行 | 60～65 | 54～59 | 0 |

这说明电机运行确实增加了控制计算负载，但当前负载仍远低于 10 ms 周期预算。

## 6. 问题分析与边界

M2 证明的是当前空载 UART target 条件下，电机运行没有使控制任务超出当前 `10010 μs` 容差判定。它不能证明高负载、长时间运行、正反转切换、ADC target 或物理 PWM 波形均已验证。
