## 3. 测试前基线

脚本首先发送：

```text
stop
set target uart
kp=0.05
ki=0
kd=0
t=600
status
```

设备依次返回 `OK:STOPPED`、`OK:TARGET_SOURCE_UART`、PID 设置成功文本和 `OK:TARGET_SET`。基线 status 显示：

```text
enable:0,State:IDLE,source:Uart,target:600,actual:0,delta:0,PWM:0,fault:NONE,kp:0.050,ki:0.000,kd:0.000
```

因此，异常输入开始前系统已处于计划要求的停止、安全、UART target 基线。
