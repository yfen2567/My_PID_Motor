# My_PID_Motor v2.2 参数持久化测试报告

## 1. 测试结论

结论：**PASS**

本次验证了 `kp`、`ki`、`kd` 三个 PID 参数的保存、显式加载、恢复默认值，以及断电重启后的加载行为。保存后的 `0.060/0.010/0.020` 在断电重启后仍被加载；未保存的 RAM 修改会被 `load params` 覆盖；`reset params` 写入默认值后，断电重启仍保持 `0.050/0.000/0.000`。

全程保持 `enable:0`、`State:IDLE`、`PWM:0`、`fault:NONE`，未出现 `ERR:PARAMS_SAVE_FAILED` 或 `ERR:PARAMS_LOAD_FAILED`。

本结论仅覆盖当前 STM32F103 硬件、当前 v2.2 固件和本次命令序列；不外推为 Flash 寿命、掉电原子性、损坏恢复、跨版本迁移或工业级可靠性结论。

## 3. PP-001 保存并在断电重启后恢复

测试先在停止状态设置：

```text
kp=0.06
ki=0.01
kd=0.02
save params
```

设备返回：

```text
OK:KP_SET
OK:KI_SET
OK:KD_SET
OK:PARAMS_SAVED
```

保存前 status 已显示：

```text
enable:0,State:IDLE,PWM:0,fault:NONE,kp:0.060,ki:0.010,kd:0.020
```

随后执行断开并恢复 MCU 供电。原始日志中 `ms` 从 `13003` 回到 `3`，证明固件重新启动；启动后的多条 status 均显示：

```text
enable:0,State:IDLE,PWM:0,fault:NONE,kp:0.060,ki:0.010,kd:0.020
```

因此，已保存参数在真实重启后正确恢复。重启后 `source` 回到 ADC、`target` 随 ADC 变化，符合它们不持久化的设计。

## 4. PP-002 显式加载覆盖未保存 RAM 参数

在停止状态将运行时参数改为：

```text
kp=0.07
ki=0.03
kd=0.04
```

status 确认当前 RAM 参数为：

```text
kp:0.070,ki:0.030,kd:0.040
```

随后发送：

```text
load params
```

设备返回：

```text
OK:PARAMS_LOADED
```

后续 status 显示：

```text
kp:0.060,ki:0.010,kd:0.020
```

因此，显式加载正确覆盖未保存的 RAM 参数，没有出现跨字段混合或部分更新。

## 5. PP-003 恢复默认值并在断电重启后保持

在停止状态发送：

```text
reset params
```

设备返回：

```text
OK:PARAMS_RESET
```

随后 status 显示默认参数：

```text
kp:0.050,ki:0.000,kd:0.000
```

再次执行断开并恢复 MCU 供电。日志中再次出现启动阶段 `ms:3`，后续 status 持续显示：

```text
enable:0,State:IDLE,PWM:0,fault:NONE,kp:0.050,ki:0.000,kd:0.000
```

因此，`reset params` 不仅恢复当前 RAM 默认值，也已将默认值写入非易失存储并在重启后保持。

## 7. 边界说明

本次不验证以下内容：

- Flash 擦写寿命；
- 保存过程中突然掉电的原子性；
- CRC 损坏、坏页或版本字段不兼容时的恢复策略；
- 跨固件版本的数据迁移；
- 其他硬件、供电和参数组合下的相同行为。
