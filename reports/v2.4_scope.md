# My_PID_Motor v2.4 控制性能与异常证据范围

## 1. 版本定位

v2.4 是 My_PID_Motor 的控制性能与异常证据收尾版本。它不再扩展 CAN、FOC、Bootloader、联网、LVGL 或复杂上位机，而是回答两个问题：

1. 当前单电机闭环的控制性能到底是多少；
2. 关键异常发生时，系统如何检测、停机、保存证据和恢复。

v2.4 的重点不是增加功能数量，而是把“控制器能运行”推进到“控制器的性能和失败边界可测、可解释、可回归”。

## 2. 核心范围

### 2.1 控制性能

- 阶跃响应：至少 `500 -> 800 -> 500`；
- 稳态误差；
- 超调量与超调率；
- 上升时间；
- 调节时间；
- 当前 PID 参数基线与参数对比；
- 目标斜坡或抗积分饱和，至少完成其中一项；
- PWM 输出接近饱和时的行为；
- 不可达目标或持续误差下的行为。

### 2.2 异常证据

- 编码器无反馈/等效丢失；
- 编码器跳变或方向异常的安全边界；
- PWM 饱和 fault；
- 堵转或等效堵转；
- fault snapshot 内容、触发时机、停机动作和复位行为；
- 原始串口日志、测试报告和回归表。

## 3. 当前第一阶段

第一阶段固定为：

```text
v2.4.1 Step Response and Steady-State Baseline
```

先不修改 PID 算法，使用当前默认基线：

```text
Kp=0.05, Ki=0, Kd=0
```

通过阶跃实验先测出当前控制器的真实行为，再决定是否引入目标斜坡或抗积分饱和。没有基线数据时，不直接修改控制算法。

## 4. 指标口径

| 指标 | 当前定义 |
| --- | --- |
| 稳态误差 | 阶跃阶段最后 1 秒 `actual - target` 的平均值 |
| 超调量 | `actual` 超过目标的最大值；负向阶跃按绝对方向处理 |
| 超调率 | 超调量 / 阶跃幅度 |
| 上升时间 | 从阶跃幅度的 10% 到 90% 所需时间 |
| 调节时间 | 进入目标误差带并持续保持的时间 |
| 初始误差带 | 先采用目标绝对误差 ±10%，并在报告中说明测速分辨率限制 |
| 采样周期 | 通过 status 日志中的 `ms` 字段复核；脚本目标采样间隔约 100 ms |

当前编码器测速存在量化误差，因此不能直接使用过窄误差带，也不能把一次 `actual` 跳变直接解释成真实机械速度突变。

## 5. 封版门

v2.4 核心封版至少需要：

1. 两到三项控制性能指标有明确计算口径和原始日志；
2. 至少两组可复核阶跃或负载扰动结果；
3. 参数对比或目标斜坡/抗积分饱和至少形成一项有证据的结论；
4. 三到四类核心异常有安全、可重复的测试方案；
5. fault snapshot、停机和复位行为有原始日志；
6. README、测试计划、报告、回归脚本和 Release 说明同步；
7. 所有未测项和不能外推的边界明确写出。

## 6. 明确不纳入

- CAN、CANDiag；
- 三相逆变、BLDC/PMSM、FOC、SVPWM；
- Bootloader、OTA、联网、复杂 UI、复杂上位机；
- 工业级、车规级或功能安全级结论；
- 没有测量工具时伪造 GPIO 波形或电气保护证据。
