# My_PID_Motor v2.2-param-persist-and-abnormal-regression 范围说明

## 1. 阶段定位

`v2.2-param-persist-and-abnormal-regression` 是参数持久化与异常行为回归阶段。本阶段只处理可复现、可留存原始日志、可形成明确 PASS/FAIL 的验证内容，不扩展电机控制算法，也不重复 v2.1 人工轻载负载扰动测试。

本文是范围与计划说明，不代表 v2.2 功能已经实现或测试已经通过。

## 2. 纳入范围

1. **参数持久化**：验证参数保存、加载、复位后恢复以及恢复默认值；
2. **非法/越界命令回归**：验证错误输入得到明确拒绝，且不会破坏 enable、State、target、PID 和 fault 等系统状态；
3. **run/stop 行为回归**：验证启动、停止、再次启动以及停止后的软件状态和 PWM 命令边界；
4. **status 字段完整性检查**：验证字段齐全、顺序与格式稳定，并能用于上述回归的状态核对。

## 3. 当前代码事实与实现门禁

- 当前已有命令包括 `run=1`、`stop` / `run=0`、`t=...`、`kp=...`、`ki=...`、`kd=...`、`rst`、`set target uart`、`set target adc`、`status`、`help`、`get fault`。
- v2.2 参数持久化协议已经冻结，但本文不代表相应代码已经实现。
- 持久化字段只包括 `kp`、`ki`、`kd`。
- 不持久化 `target/source`、`enable/State`、`actual/PWM/fault`、`adc1/adc2` 或任何运行态 status 字段。
- 正式命令为：
  - `save params`：保存当前 `kp/ki/kd` 到非易失存储；
  - `load params`：从非易失存储加载 `kp/ki/kd`，覆盖当前 RAM 参数；
  - `reset params`：恢复固件默认 `kp/ki/kd`，并写入非易失存储，使复位后仍保持默认值。
- 返回协议固定为：
  - `OK:PARAMS_SAVED`
  - `OK:PARAMS_LOADED`
  - `OK:PARAMS_RESET`
  - `ERR:PARAMS_SAVE_FAILED`
  - `ERR:PARAMS_LOAD_FAILED`
  - `ERR:BAD_CMD`
- `reset params` 写入非易失存储失败时使用 `ERR:PARAMS_SAVE_FAILED`；不新增未冻结的错误文本。
- 当前 status 字段为：`ms,enable,State,source,target,actual,delta,PWM,adc1,adc2,fault,kp,ki,kd`。
- 当前目标解析范围为 `-1000～1000`；绝对值小于 500 的目标会由当前命令任务返回 `ERR:TARGET_BELOW_MIN`。
- 当前 PID 命令接受范围为 `0～100`，非法解析或越界返回 `ERR:BAD_CMD`。

## 4. 证据规则

- 每项测试保存完整 TX/RX 原始串口日志，不删除异常行；
- `OK:CMD_QUEUED` 只证明命令入队，执行结果必须结合后续 status 或复位后状态确认；
- 计划中的期望输出不是实测结论；
- 日志至少记录日期、固件/commit、串口工具、波特率、真实 CRLF、命令序列和人工操作时刻；
- 如实际协议与计划不一致，先更新计划或记录差异，不为得到 PASS 选择性忽略输出。

## 5. 建议执行顺序

1. 按冻结协议实现参数保存、加载和恢复默认值，不扩展持久化字段；
2. 执行参数保存、加载、复位恢复和默认恢复测试；
3. 执行非法/越界命令回归；
4. 执行 run/stop 行为与 status 字段完整性联合回归；
5. 汇总原始日志、单项报告、构建记录和最终证据索引。

## 6. 不纳入 v2.2

- CAN、Bootloader、LVGL、上位机；
- 新的负载扰动测试；
- FOC 或复杂控制算法；
- Ki/Kd 控制效果调参；
- ADC target 专项验证；
- 示波器、逻辑分析仪、电流测量；
- 正反转直接切换。

本阶段结果不能外推为工业级可靠性、长期可靠性、Flash 擦写寿命、突然断电原子性、CRC 损坏恢复、跨版本迁移、复杂负载能力或其他硬件平台上的相同行为。
