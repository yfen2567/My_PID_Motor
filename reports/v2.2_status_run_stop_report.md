# My_PID_Motor v2.2 status/run/stop/restart 测试报告

## 1. 测试结论

结论：**PASS**

在 UART target=600、`kp=0.050`、`ki=0.000`、`kd=0.000` 条件下，两次 `run=1` 均进入 `enable:1,State:RUN`，实际速度为正、PWM 为正、fault 为 NONE。两次 `stop` 后均回到 `enable:0,State:IDLE,PWM:0`，最终 `get fault` 返回 `FAULT_SNAPSHOT_NONE`。

本结论只证明本次串口可见的软件状态、命令边界和实际转速反馈链路在当前工况下正确；不证明 PA8 实际 PWM 波形、电机电流、制动距离、转矩、长期启停寿命或硬件级功能安全。

## 3. 初始停止状态与配置基线

脚本依次发送：

```text
stop
status
set target uart
kp=0.05
ki=0
kd=0
t=600
status
```

控制命令均得到对应 `OK:` 返回。运行前 status 显示：

```text
enable:0,State:IDLE,source:Uart,target:600,actual:0,delta:0,PWM:0,fault:NONE,kp:0.050,ki:0.000,kd:0.000
```

日志中的 status 均使用冻结的 14 字段顺序：

```text
ms,enable,State,source,target,actual,delta,PWM,adc1,adc2,fault,kp,ki,kd
```

## 4. 第一次运行与停止

发送 `run=1` 后，设备返回：

```text
OK:RUN
```

约 2 秒运行期间，实际 status 包含：

```text
enable:1,State:RUN,source:Uart,target:600,actual:514,delta:2,PWM:132,fault:NONE
enable:1,State:RUN,source:Uart,target:600,actual:557,delta:3,PWM:130,fault:NONE
```

实际速度和 PWM 均为正，方向与正 target=600 一致；本轮不要求实际速度精确等于 600。

随后发送 `stop`，设备返回：

```text
OK:STOPPED
```

等待后 status 显示：

```text
enable:0,State:IDLE,source:Uart,target:600,actual:0,delta:0,PWM:0,fault:NONE
```

## 5. 第二次运行、重启能力与最终停止

第一次停止后再次发送 `run=1`，设备第二次返回：

```text
OK:RUN
```

第二次运行期间实际 status 包含：

```text
enable:1,State:RUN,source:Uart,target:600,actual:514,delta:2,PWM:132,fault:NONE
enable:1,State:RUN,source:Uart,target:600,actual:557,delta:3,PWM:130,fault:NONE
```

这证明第一次 stop 后，系统仍可重新进入运行状态且串口继续响应。

最终发送 `stop` 后，status 连续显示：

```text
enable:0,State:IDLE,source:Uart,target:600,actual:0,delta:0,PWM:0,fault:NONE
```

最后发送：

```text
get fault
```

原始日志返回：

```text
FAULT_SNAPSHOT_NONE
```

该文本与同一 UART 接收块内的周期 status 连续写入，因此只在该块第一行具有时间前缀；原文完整保留，不是响应缺失。

- PA8 引脚实际 PWM 电平是否归零；
- 方向脚实际电平、电机电流、转矩和制动距离；
- 负载扰动、正反转直接切换、ADC target 或精确动态控制性能；
- 长期启停寿命、硬件级保护和所有异常情形。
