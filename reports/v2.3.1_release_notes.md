# My_PID_Motor v2.3.1 Release Notes

## 1. 版本定位

`v2.3.1-timing-observability` 是基于 v2.2 主干的 ControlTask 软件时序观测版本。它增加了 DWT 周期测量、时序快照、串口 `timing stats` 查询、两路 GPIO 观测探针、时序聚合字段和 M0-M3 软件实测证据。

本版本是软件时序观测版本，不是完整的硬件时序验证版本。M4 所需的 PA5/PA6 逻辑分析仪或示波器波形尚未取得，暂记为延期。

## 4. 主要新增能力

- `timing stats` 串口查询；
- 当前周期、任务执行时间和控制逻辑执行时间；
- 周期/执行时间的样本数、最小值、最大值和最大绝对抖动；
- `GPIO_CYCLE` / `GPIO_TICK` 两路软件观测探针；
- 完整 M0-M3 LLCom 脚本、原始日志和报告。

## 5. 已知边界

- M4 GPIO 波形尚未用外部仪器验证；
- 不包含高负载、长时间稳定性、极限队列压力或工业级实时性结论；
- 当前 `timeout_count` 使用 `10010 us` 周期容差；原始 `period_us` 仍保留用于后续抖动分析；
- v2.2 中已知的 UART 异步发送生命周期问题仍按版本边界保留，后续版本处理。
